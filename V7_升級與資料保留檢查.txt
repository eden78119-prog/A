原始版本：工程工具箱 V6 穩定版

本次原則：

2. 保留 V6 使用的 localStorage 資料鍵：engineering_toolbox_v6_stable。
3. V7 不更換資料鍵，因此同一個 GitHub Pages 網域更新後，原 V6 本機資料可繼續使用。
4. V7 啟動時只會補齊缺少的核心欄位，不會刪除既有欄位，也不會刪除未知欄位。
5. 新增工程總覽、快速入口、V6 資料完整性檢查。
6. Service Worker 快取版本升級為 V7，避免舊快取長期覆蓋新版本。

projects / quotes / materials / labor / expenses / records / photos / invoices / memo

工程成本／利潤、請款管理、工程備忘錄、資料備份／還原。

結論：
V7 是在 V6 穩定版上做相容升級，不是重新製作或刪除 V6。
